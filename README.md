## 📌 Project Overview

This engine ingests and models blockchain transaction data to deliver actionable intelligence for security analysts, compliance teams, and forensic investigators. It provides granular visibility into transactional volume, gas fee volatility, entity profiling, and anomalous transfer patterns.

---

## 🔥 Key Features

* **Ecosystem Overview:** Executive-level KPI metrics tracking total volume, average gas fees, active wallet addresses, and risk score alerts.
* **Entity & Wallet Profiler:** Deep-dive analytics on individual wallet behaviors, transaction distributions, and risk flags.
* **Multi-Hop Money Trail Tracer:** Visualization of multi-step transaction paths to uncover hidden fund movements and layer structuring.
* **Live Whale Threat Feed:** Real-time monitoring of high-value transactions and potential market/security threats.

---

## 🛠️ Tech Stack & Architecture

* **Language:** Python 3.11
* **Dashboard / UI:** Streamlit
* **Data Manipulation & Processing:** Pandas
* **Data Visualization:** Plotly Express & Plotly Graph Objects
* **Deployment & Hosting:** Streamlit Cloud integrated with GitHub
